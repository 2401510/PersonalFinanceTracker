# PersonalFinanceTracker

Простое приложение на WPF для учета расходов.

## Возможности

- Добавление, редактирование и удаление расходов
- Фильтрация по категории и диапазону дат
- Статистика по категориям
- Импорт/экспорт в JSON и CSV

## Стек

- Язык программирования: C#
- Архитектура: MVVM
- xUnit для тестов
